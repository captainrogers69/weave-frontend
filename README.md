# weave-site

The Weave website, deployed on Netlify (static, no build step).

- `/`: landing page
- `/privacy/`: privacy policy (the URL for the App Store, Play Store and Microsoft Store)

Deploy: connect this repo in Netlify (Add new site → Import from Git). Leave the build command empty and set the publish directory to `.`. Later, add the custom domain `weave.mobilemayank.com` (Netlify → Domain management).
